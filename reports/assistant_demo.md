# 广告转化分析助手示例问答

**1. 数据集整体转化率是多少?**
* **Answer**: 数据集整体转化率为 **1.89%**。该数值由正样本（“购买”行为）9,021 条与总样本量约 47.8 万条（含负样本 469,117 条）计算得出，符合上下文明确陈述的“整体转化率为 **1.89%**，属于典型的高偏斜二分类问题”。这一低转化率进一步印证了正负样本极度不平衡的特性，也解释了为何建模中需特别关注样本不均衡问题，并优先采用 AUC、F1-score 等指标而非准确率进行评估。
* **Sources**: 
- model_explain.md
- eda_report.md

**2. 哪些因素会提高转化概率?**
* **Answer**: 根据提供的上下文，能提高转化概率的因素包括：**低价格等级（如 item_price_level=4）与高销量等级（如 item_sales_level=15.0）的组合**，该模式在历史数据中与高转化强相 关；其中 item_sales_level 作为动态行为特征权重较高，起关键正向作用。此外，极低价格等级（如 item_price_level=3）本身也被模型识别为强正向信号，可单独驱动高预测概率 （95.56%），但存在泛化风险。需注意：这些仅反映统计关联，非因果证据；实际提升转化需结合 A/B 测试验证，避免仅凭单一特征（如降价或刷销量）直接干预。其他特征（如收藏 、浏览、店铺评分等）未在高/低预测样本解释中被提及，故无法确认其正向影响。
* **Sources**: 
- model_explain.md
- data_dictionary.md

**3. Week5 的特征工程带来了什么改进?**
* **Answer**: Week5的特征工程通过分阶段实验验证了不同特征组合的效果。相比初期AUC仅0.5458的基线，修正后的基础模型（Exp 1）已提升至0.6616。加入时间特征后（Exp 2），AUC进一步提升 至0.6641（+0.0025），故予以保留；再加入列表长度特征（Exp 4），AUC达0.6647（较Exp 2再+0.0006），LogLoss也同步下降至0.6384，因此该组合被确认有效并保留。而ID频次特征（Exp 3）未带来增益（AUC回落至0.6616），被剔除。整体表明：时间特征和列表长度特征对模型判别能力有正向贡献，ID频次特征则无益。
* **Sources**: 
- model_explain.md
- exp_week05.md

**4. 模型最重要的特征是什么?**
* **Answer**: 根据提供的上下文，模型最重要的特征是 `item_sales_level`。在“高预测概率样本”解释中明确指出：“item_sales_level作为动态行为特征权重较高，推动模型输出高置信度预测”； 在“低预测概率样本”中进一步强调：“item_sales_level=2.0反映市场接受度偏弱，作为核心负向特征显著拉低预测概率”。此外，[exp_week04.md] 提到“尝试对类别特征做 target encoding”，而 [eda_report.md] 强调对高基数类别特征（如 `item_category_list`）需降维处理，反衬出 `item_sales_level` 这一数值型、行为导向特征未被归入需特殊处理的高基数类别，且其影响被反复突出为“核心”“权重较高”“显著拉低”，表明其在模型决策中具有主导性作用。
* **Sources**: 
- model_explain.md

**5. 为什么用户活跃度会影响转化?**
* **Answer**: 根据提供的context，用户活跃度并未被直接定义或分析。数据字典中未出现“用户活跃度”字段，EDA报告和模型解释表也未提及该概念。模型特征重要性排名中，与用户相关的仅有`user_occupation_id_2002.0`（职业ID，排名第15，权重0.142），解释为“某类特定职业群体（比如学生或白领）表现出了超强购买力”，反映的是用户身份属性而非活跃度。其他用户侧字段如`user_gender_id`、`user_age_level`、`user_star_level`均未进入Top 20重要特征。因此，**context中没有任何信息支持“用户活跃度影响转化”的因果关系或机制解释**。无法基于给定材料回答该问题。

**6. 哪些商品更容易成交?**
* **Answer**: 根据提供的上下文，更容易成交的商品具有以下特征：价格等级较低（`item_price_level`为负向特征，高价商品历史转化率低）；销量等级较高（`item_sales_level`均值11.16，热 销商品占主导，且与转化存在统计关联）；收藏等级和浏览量等级（`item_collected_level`、`item_pv_level`）较高，反映用户兴趣热度；类目与属性（`item_category_list`、`item_property_list`）及品牌（`item_brand_id`）可能影响匹配度，但具体方向需结合模型未显式呈现的交互作用。需注意：这些是统计相关性结论，非因果关系；且标签极度不均衡（转化率仅1.89%），模型倾向预测“未成交”。实际决策应通过A/B测试验证，避免单点干预。

**7. 为什么评分高的店铺转化率更高?**
* **Answer**: 根据提供的上下文，评分高的店铺转化率更高，是因为模型解释中显示 `shop_star_level_5013.0` 和 `shop_star_level_5006.0` 分别位列第13和第14重要特征，权重得分达0.157和0.154，表明高星级店铺（如5013≈5.01星、5006≈5.00星）显著正向影响成交。同时，`shop_review_num_level_12.0` 和 `13.0` 也进入前12，说明评价数量多（对应高星级店铺通常积 累更多评价）进一步增强用户信任。结合数据字典，`shop_star_level` 是脱敏后的星级编码，数值越高代表服务口碑越好；而 EDA 报告指出该字段与转化目标强相关。因此，高评分 店铺通过提升用户信任感，降低了购买决策门槛，从而提高转化率。

**8. Week6 训练框架做了什么改进?**
* **Answer**: Week6训练框架的改进包括：针对样本不均衡问题，采用加权损失函数（如`class_weight='balanced'`）或SMOTE过采样/欠采样策略，并使用AUC、F1-score替代准确率作为评估指标； 对缺失值（如`user_gender_id`）不再简单填充，而是将其编码为独立类别（如“-1”或“unknown”），以保留潜在行为差异；对高基数类别特征（如`item_category_list`、`item_city_id`）实施降维，例如提取一级类目、使用目标编码或Embedding；同时依据数据的时间序列特性，严格按时间顺序划分训练集（前6天）与验证集（最后2天），并考虑将9月18日流量激 增识别为大促事件，引入“是否大促日”作为辅助特征。
* **Sources**: 
- model_explain.md
- eda_report.md

**9. 哪些特征对模型帮助不大?**
* **Answer**: 根据提供的上下文，对模型帮助不大的特征包括：
- **高基数 ID 特征**：`user_id`、`item_id`、`shop_id`、`item_brand_id`，因其类别数量极大，直接 One-Hot 编码会导致维度爆炸和严重过拟合（见 exp_week05.md）；       
- **复合字符串特征**：`item_category_list` 和 `item_property_list`，为含分号的多值字符串，作为单一类别特征会生成海量无效稀疏矩阵（exp_week05.md）；
- **缺失/无效特征**：`user_pv_level` 和 `user_city_id`，在数据字典和原数据中不存在，移除以保证代码正常运行（exp_week05.md）；
- 此外，`user_gender_id` 若盲目用均值/众数填充而非保留缺失为独立类别，也可能引入噪声（eda_report.md）。

**10. 如果要提升转化率,运营应该关注什么?**
* **Answer**: 运营应将特征重要性作为假设生成工具，重点关注价格竞争力（如`item_price_level`）与销量热度（如`item_sales_level`）的协同效应——高销量等级（如15.0）与较低价格等级（如4）组合在历史数据中强关联高转化。但需警惕：特征关联不等于因果，降价或刷销量等单点干预未必提升转化（如高价商品可能因品牌定位维持高转化）。误判样本显示仅依赖低价（`item_price_level=3`）易导致过拟合，凸显多特征联合判断的必要性。所有策略调整前，必须通过A/B测试验证因果效果；同时注意样本偏差与泛化风险，避免结论外推至新用户群或市场环境。
* **Sources**: 
- model_explain.md
